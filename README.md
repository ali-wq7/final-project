# لُبس — مشروع متجر ملابس

متجر متجاوب باستخدام HTML وCSS وJavaScript، مع Bootstrap وFlexbox وREST API، بدون عناصر `div`.

## التشغيل

فك الضغط مع الاحتفاظ بمجلد `assets`، وشغّل المجلد بإضافة Live Server في VS Code أو `python -m http.server 8000` ثم افتح `http://localhost:8000`. يمكن فتح `index.html` مباشرة للتصفح؛ يفضّل localhost أو الرابط المنشور لتسجيل الحسابات باستخدام Web Crypto. الصور والخطوط وBootstrap موجودة محليًا، وتحديث API يحتاج الإنترنت.

## المميزات

- العربية RTL والإنجليزية LTR لجميع الواجهة والنوافذ.
- وضع فاتح وداكن، مع حفظ اللغة والمظهر في `localStorage`.
- هوية موحدة: شعار L، أخضر ليموني `#d8fc71`، حبر داكن `#181b16`، وخط Tajawal للعربية وArial للإنجليزية.
- صور قطع ملابس فقط، بدون أشخاص.
- شريط تنقل مباشر للمنتجات والرجال والنساء والتخفيضات ومعلومات المتجر.
- تصنيفات، بحث بالعربية والإنجليزية، وترتيب بالاسم والسعر.
- تفاصيل المنتجات واختيار المقاس ودليل المقاسات.
- سلة ومفضلة محفوظتان، وتغيير الكمية وحذف المنتجات.
- كود `LUBS10` لخصم 10%؛ الشحن 25 ر.س ومجاني من 300 ر.س قبل الخصم.
- إنشاء حساب محلي، تأكيد كلمة المرور، منع تكرار البريد، تسجيل دخول وخروج، وحفظ الجلسة.
- مشتق كلمة المرور باستخدام PBKDF2 مع salt، بدون حفظ كلمة المرور كنص واضح.
- طلب تجريبي مع تحقق من الحقول ورقم للطلب؛ بيانات التوصيل لا تُحفظ ولا تُرسل.
- جلب منتجات من API مع مهلة 8 ثوانٍ، والتحقق من الاستجابة، وعرض النسخة المحفوظة عند تعذر الاتصال.

## تنظيم الكود

بُسّط المشروع من ستة ملفات كود خاصة إلى ثلاثة، مع كتالوج واحد ونافذة `dialog` واحدة يعاد استخدامها. لا توجد أدوات بناء أو مكتبات إضافية.

| الملف | الوظيفة |
| --- | --- |
| `index.html` | الهيكل الدلالي، الأيقونات، وأدوات المتجر |
| `style.css` | الهوية، متغيرات الوضع الداكن، Flexbox والتجاوب |
| `script.js` | الترجمة، المنتجات، السلة، المفضلة، الحسابات وAPI |
| `assets/` | الصور والخطوط وBootstrap CSS والتراخيص |
| `SOURCES.md` | مصادر الأصول |

استخدام Bootstrap ظاهر في `btn` و`form-control` و`form-select` و`d-flex` و`gap` و`flex-wrap` وغيرها. التخطيطات الرئيسية تعتمد Flexbox. عناصر HTML مثل `header` و`nav` و`main` و`section` و`article` و`figure` و`dialog` تحل محل `div`.

## API

يستخدم `loadProducts()` في `script.js` طلبات `fetch` متوازية إلى:

- `https://dummyjson.com/products/category/mens-shirts`
- `https://dummyjson.com/products/category/womens-dresses`

تُربط أربعة منتجات معروفة بصور قطع ملابس محفوظة محليًا وأسماء مترجمة. الأسعار توضيحية بالريال بمعامل ثابت 3.75؛ ليست أسعار صرف حية. المجموعة الأساسية متاحة حتى عند تعذر API.

## localStorage

| المفتاح | البيانات |
| --- | --- |
| `lubs-store-v1` | السلة والمفضلة |
| `lubs-accounts-v1` | الحسابات التجريبية ومشتقات كلمات المرور |
| `lubs-session-v1` | بريد الحساب الحالي |
| `lubs-api-products` | أسعار منتجات API المحفوظة |
| `lubs-prefs-v1` | اللغة والوضع الفاتح/الداكن |

تظل بيانات الإصدار السابق متوافقة. التخزين خاص بالمتصفح وأصل الموقع ولا يتزامن بين الأجهزة. استخدم بيانات وهمية وكلمة مرور غير مستخدمة في حساباتك؛ هذه نسخة تعليمية وليست نظام حسابات أو دفع حقيقيًا.

## عرض المشروع

1. بدّل إلى الإنجليزية والوضع الداكن ثم حدّث الصفحة للتأكد من حفظهما.
2. جرّب البحث والتصنيفات وترتيب الأسعار وتحديث المنتجات من API.
3. أضف قطعة للمفضلة، واختر مقاسًا وأضفها للسلة ثم حدّث الصفحة.
4. أنشئ حسابًا تجريبيًا وسجّل الخروج والدخول.
5. غيّر كمية السلة، طبّق `LUBS10`، وأكمل الطلب التجريبي ببيانات وهمية.
